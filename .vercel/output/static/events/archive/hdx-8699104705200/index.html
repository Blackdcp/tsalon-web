一、活动背景

在 ChatGPT、Midjourney、Stable Diffusion 等创新应用的推动下，相信大家或多或少听过 Prompt 。

开发者群体里已经有人投身于两种方向：一部分开发者瞄准了大模型企业的 API，想要在 AI 2.0 的风口上成为弄潮儿；另一部分开发者则聚焦在创造 Prompt，围绕打造应用赚到第一桶金。

T技术沙龙将于5月13日，在上海举办 Prompt Engineering 实践日，我们将邀请 GPT 领域的专家、开发者与跨界玩家，共同探讨 Prompt Engineering 的机遇与挑战。
