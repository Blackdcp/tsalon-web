AI 从 Demo 到生产｜Agent 与 AI Native 应用的工程实践

做出一个能跑的 AI Demo 已经不难，难的是把它变成一个能够持续运行、迭代和交付的产品。本次活动邀请记忆张量、Zion、PPIO 的一线实践者分享架构设计。

活动背景

做出一个能跑的 AI Demo 已经不难，难的是把它变成一个能够持续运行、迭代和交付的产品。

**让记忆持续：**让项目背景、历史决策与任务进展跨会话、跨任务、跨 Agent 延续。 **让后端可控：**让数据库、API、业务工作流与角色权限能够稳定生成、维护和交接。 **让调用高效：**在多模型和高频调用场景中，兼顾模型效果、延迟、成功率与成本。

本次活动邀请记忆张量 MemTensor、Zion、PPIO和 FastGPT 的一线实践者，分别围绕跨 Agent 长期记忆、Vibe Coding 后端开发与智能模型网关，分享 AI 应用从技术 Demo 走向真实产品的架构设计与工程实践。

分享详情

让所有 AI 都记得同一个你：Memmy 与 MemOS 的记忆架构和工程实践

宗玥 (AI 全栈开发者，Memmy 技术 PM)

AI 全栈开发者，Memmy 技术 PM，既负责需求与技术方案设计，也亲自参与 Agent Runtime、跨 Agent 记忆接入、本地服务及云端业务的代码实现，持续探索 Agent Memory 从技术 Demo 到真实产品的工程化路径。

随着 Cursor、Claude Code、Codex 等 Agent 逐步进入开发工作流，项目背景、历史决策与任务进展也开始分散在不同工具之中。如何打破工具之间的记忆孤岛，使上下文能够跨会话、跨任务、跨 Agent 持续延续，已成为 Agent 从单次调用走向长期运行必须解决的关键问题。

本次分享将从记忆张量自研的 Agent Memory 算法出发，介绍 MemOS 如何为 AI 应用与智能体系统提供记忆写入、组织、检索、更新和治理能力，以及 Memmy 如何基于 MemOS 的记忆能力，将多 Agent 历史沉淀为可持续使用的个人长期记忆。内容还将涵盖 Memmy 的产品设计、系统架构、历史导入与任务接续，并结合真实 Demo，拆解跨 Agent 长期记忆从底层能力到产品落地的完整链路。

更聪明的 Token，更便宜的智能：PPIO智能模型网关实践之道

陈嘉琪

在大模型应用进入 Agent 化阶段后，模型调用系统面临新的工程挑战：如何在多模型之间进行动态选择？如何判断哪些任务需要强模型，哪些任务可以交给轻量模型？如何在高并发、高频调用下同时保证延迟、成功率和成本可控？这些问题，已经超出了传统 API 网关的能力边界。

本次分享将从工程实现视角出发，介绍 PPIO 智能模型网关在 MoM 混合模型推理、模型智能路由、上下文压缩等方面的设计思路。分享将结合深度研究、企业知识问答、内容生成、代码辅助等典型场景，展示智能模型网关如何把复杂的模型选择、调用优化和质量控制能力封装成统一服务，让开发者可以更专注于 Agent 业务逻辑，让 Agent 真正具备长期、低成本、可规模化运行的基础。

拯救被后端绊住的 Vibe Coding 开发者

覃貌Tim (Zion)

越来越多没有工程背景的人，靠 AI 编程工具把想法做成了能跑的Demo ——描述一个页面、一个交互，AI 就能生成代码，跑起来看效果。

但做到一定阶段，这些人几乎都会撞到同一道墙：页面容易生成， 后端业务逻辑却很难交给 AI 稳定地生成和维护和交接。

Zion 为此提供了一套开发 Plugin 和平台 Copilot，让用户可以通过自然语言描述生成清晰易懂的数据库、API配置、复杂业务逻辑工作流、AI 智能体、角色权限管理并自动部署到云端，让后端开发变成可控可持续迭代。

让 Agent 真正工作起来：从模型、记忆到可交付应用

FastGPT 解决方案负责人

FastGPT 解决方案负责人，长期关注企业级 AI Agent 的应用落地与解决方案设计，致力于将大模型、知识库、工作流、工具调用等能力，转化为可部署、可交付、可持续迭代的 AI 应用。

模型让 Agent 具备思考能力，记忆让 Agent 能够理解上下文，工具让 Agent 能够执行任务。但要让这些能力真正服务于用户，还需要一个应用层将它们组织、编排和发布起来。

本次分享将从 AI Agent 应用落地的角度出发，介绍 FastGPT 如何连接模型、知识库、上下文、工作流和工具调用，帮助开发者将一个能运行的 Demo，逐步构建为可调试、可部署、可交付的 Agent 应用。
