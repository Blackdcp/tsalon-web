# 2026-09-16

## GEO（生成式引擎优化）全站审计

对 design-systems/01-protocol/prototype（Astro 静态 + Vercel，www.tsalon.tech）做了一轮 GEO 诊断。

### 站点现状基线
- sitemap 共 73 个 URL；内容 = 8 篇文章 + 17 期 T Chat 访谈页 + 3 场活动 + 6 场历史活动。
- 技术面 A 级：Astro 静态输出 HTML 全可抓、中英双语 hreflang+og:locale:alternate、
  Organization/Event/Article/VideoObject/CreativeWorkSeries JSON-LD 齐全、有 content-index.json。
- TokenRank 与 /whenreset/ 为 `prerender = false` SSR，数据在 HTML 里，爬虫可见，且已在 sitemap 中（各 4 / 2 条）。

### 定位出的硬伤（按优先级）
1. **llms.txt 失效（最严重）**：`public/llms.txt`（16 行英文精简版）覆盖了 `src/pages/llms.txt.ts`
   动态生成的全量中文版。线上实测只返回精简版，dist/client/llms.txt = 970B 即静态那份。
   修法：删掉 `public/llms.txt`，让 APIRoute 生效。
2. **TokenRank / 重置雷达完全没进 llms.txt**（两个源文件 grep 均无命中）——唯一的一手数据资产缺席 AI 入口。
3. **无 llms-full.txt**。
4. **robots.txt 仅 `User-agent: *`**：无 GPTBot/ClaudeBot/PerplexityBot/Google-Extended 显式声明，
   且未 Disallow `/api/`（db-maint、db-maint2、fix-db 等运维端点暴露）。
5. **/whenreset/（AI 编程额度重置雷达）零 JSON-LD** —— 全站最像 AI 问答的页面却没结构化数据。
6. 文章 author 是 `Organization: T Salon 编辑部`，非 Person；无作者主页。
7. 有视觉面包屑无 BreadcrumbList；无 RSS/feed。
8. 17 期 T Chat 只有 VideoObject 指向站外视频，站内无文字稿（最大的独家文本金矿）。
9. 8 篇文章 frontmatter 带 `citations: SegmentFault 原文`，疑为二手转述——原创存疑，影响能否被引用。

### 待用户确认
- 8 篇文章是否原创；TokenRank 是否愿意做成对外数据源（methodology + Dataset + stats.json）。

结论：技术底座好，问题集中在「AI 入口文件失效 + 一手资产未机器可读化」，P0 约 1 天可全部修完。

### 排查教训
- 本项目用 zsh，**grep 的 `\|` 转义在 Bash 工具里常失效**导致假阴性
  （曾误判「中文文章页无内链」，实际第 211-219 行有上下篇渲染）。
  涉及正则多选一律改用 Grep 工具或 `grep -E` / python。
